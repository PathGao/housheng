# 后生基础验证版

2026-10-03。用户授权自主完成基础开发并在 USB 连接的小米 10S 上验证。模型后续再选。

## 交付边界

原生 Kotlin Android APK，先验证通知、无障碍读取、截图和有限动作。默认观察模式，不联网，不作 AI 识别宣传。2026-10-03追加名单与隐私边界：真实应用须完成信息流页面适配后才能读取，当前全部关闭。浏览器和名单外应用不读取。仅验证场可以进行页面及动作测试。详见 `app-scope.md`。

用户于 2026-10-03 明确：不做李跳跳或 AdBlock 类功能，不屏蔽广告、不跳过广告、不自动点击广告跳过按钮、不绕过应用限制。只利用用户已有的应用内/系统权限管理能力及普通用户内容信息流筛选。广告及内容类型无法确认的页面一律不自动操作。该产品边界不代表任何法律合规结论。

通知来源逐个选择，空选择不采集。只保存本次进程的有限诊断记录，不长期留存通知正文。默认不清理，仅记录；开启执行后只清理用户选中来源中命中明确关键词且可清除的通知，重要类别及常驻、分组摘要保留。

页面观察仅针对选中的应用。截图显式发起，一次捕获，私有缓存保存并可删除。界面变化产生新代次，异步结果必须同时符合来源、内容代次、期限、启用状态。一次条目最多执行一次，超时和失败均保留，不排队补操作。

模型接口接受内容证据并返回保留或跳过。首版只接本地关键词判定，不包括云 API、OCR 或音频采集。端到端指标单独记录，不把本地规则的速度当成模型速度。

提供独立验证应用：可控信息流、测试通知和页面切换，让真实服务执行真实系统接口。使用真实手机验证，不以只读源码的测试替代。

## 验证预期

- 当前条目命中规则且未超时才执行。改变条目、关闭开关、切换应用、到达 500ms 期限必须拒绝执行。
- 观察模式永不执行。保留项、空规则、不可识别页面不滑动。
- 测试通知中营销条目可清理，普通、重要和常驻通知保留。
- 截图成功可预览和删除，权限关闭显示不可用，不尝试绕过系统授权。
- 安装产物运行正常，不崩溃；记录实际设备系统、截图耗时和受控滑动结果。

不依赖 Root、Shizuku，不自动关闭其他应用通知权限。不开通模型账号，不推送开发代码。
