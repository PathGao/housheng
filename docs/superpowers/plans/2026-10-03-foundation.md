# 后生基础验证实现计划

**目标：** 交付小米 10S 可安装、可验证的基础 APK，模型暂不接入。

**架构：** Android 服务采集证据，纯 Kotlin 判断与动作守卫负责期限和状态，本地界面控制授权与规则。独立 fixture 应用提供可重复的真实通知与信息流。

**技术栈：** Kotlin、Android 平台 API、Gradle、JUnit。

**依据：** ../../validation-design.md
