# 本机模型与手机管线验证

2026-10-03，Apple M5 / 24GiB / macOS 27.0.1，手机为小米10S / Android13。模型在Mac运行，手机经USB请求。本轮不等于在小米10S端侧运行模型。

## 验收范围

用户明确先验收功能管线，准确率留待提示词调整或更换Clef。默认观察；只有显式开启验证场翻页后才执行。选择已有无障碍下滑能力，没有新增马赛克遮罩或悬浮窗权限。

```text
已勾选的合成验证场普通内容
  → 后生后台线程发送文字 + 请求ID
  → 手机127.0.0.1:18765 → ADB USB转发
  → Mac本机Laya → keep / filter / uncertain
  → 手机验证响应、请求ID及有效期
  → 既有来源、页面、执行开关和500ms守卫
  → filter且全部守卫通过：实际无障碍下滑
```

广告/未知页不送模型。真实应用尚无可靠页面适配，仍禁用。浏览器和聊天页不读取。调试版只允许回环HTTP，release包实际构建并用aapt2确认无INTERNET权限。正文只在内存中处理，桥接日志仅记请求ID、标签和耗时。

## 真机结果

最终运行于2026-10-03 15:10（北京时间），以下均为小米10S实测。预期是正常模型结果能往返并驱动一次真实下滑，失败或被保护的输入不执行。

| 检查 | 结果 |
|---|---|
| Laya经USB返回类型化决策 | 通过，独立请求110ms |
| 模型filter驱动真实无障碍下滑 | 通过，第1条切到第2条，仅执行一次；页面读取至动作106ms，其中请求98ms |
| 观察模式 | 收到模型结果，保留第1条 |
| 广告、未知页、未勾选来源 | 保留，不触发模型下滑 |
| 断连、HTTP错误、超时、错请求ID、畸形/超大响应 | 拒绝结果，不能作为过滤指令 |
| 切页、关闭执行、取消来源、超过500ms的旧决策 | 不执行旧动作 |
| 在途请求期间到达的新页面 | 完成旧请求后处理最新一页，不积压中间页，不重置原观察时间 |

110ms与106ms来自不同调用，不是同一次耗时拆分，也不是手机端P95。尚未做长时间手机延迟/耗电测试。

新增回归曾在修复前真实失败：冻结后续无障碍事件，新页在忙时被记为已观察，但没有后续分类。修复保留最多一个最新待判断页面，修复后同一用例通过。原来的页面变更结果丢弃不再清空较新的待判断项。

最终通过：26项JVM测试、36项主程序真机测试、1项独立服务恢复测试、6项Python协议/指标测试。Debug及Release构建、App与验证场Lint通过。首次真机运行被锁屏干扰，未计入成功结果；解锁后的完整重跑通过。测试结束恢复服务并关闭自动执行，ADB确认页面服务实际绑定。

交付时已停止本次Mac模型进程并移除本次USB转发，避免闲置占用内存。已安装的APK、权重和环境保留。再次验证时按验证入口启动服务和转发。

## 模型基线记录

固定代码、权重和依赖，首次下载后用离线模式完成推理。原始样本、规则、SHA256、逐条结果、CPU对照和环境记录在[validation/laya](../validation/laya/README.md)。

| 指标 | M5 GPU（MPS） | M5 CPU |
|---|---:|---:|
| 评估样本 | 60条，重复3轮，共180次 | 同60条，1轮 |
| 预热后完整调用中位数 | 27.3ms | 61.2ms |
| 预热后P95 | 32.2ms | 102.8ms |
| 最慢单次 | 136.5ms | 169.5ms |
| 模型加载时间 | 2.10秒 | 1.80秒 |
| 进程峰值RSS | 2591MiB | 2589MiB |

加载时间不含Python进程启动与包导入，且文件缓存已热。首次开发运行加载7.13秒。MPS驱动分配约1282MiB，统一内存口径不能直接与RSS相加。预热后耗时包含分词、推理和结果解析，GPU计时同步，不含手机页面读取或USB往返。

9条开发样本先用于接线，另外60条在推理前固定。三分类正确27/60，24/40条非过滤内容被误过滤。CPU和MPS的60个标签全部一致，返回的四位小数概率一致。规则没有截断，全部输入没有被截断。仅此规则和此小型合成集的结果，不能推导Laya其他配置的上限，也不决定本轮管线是否通过。

每行20个独立样本，重复推理不扩大样本量：

| 预期类别 | 模型保留 | 模型过滤 | 模型不确定 |
|---|---:|---:|---:|
| 保留 | 4 | 15 | 1 |
| 过滤 | 7 | 13 | 0 |
| 不确定 | 1 | 9 | 10 |

例如，分析标题党用语的文章被判过滤，输出概率0.9079；“一碗水根治任何癌症”的虚假承诺被判保留。当前权重温度参数为1，没有本次任务的概率校准，不能把概率值解释成正确率。
