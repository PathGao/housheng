后生 0.2.4 是第一个正式签名版本，同时提供两个安装包，可以装在同一台手机上。

- `housheng-0.2.4.apk`：后生。通知清理、家庭报告、应用清单，没有网络权限，所有内容只在本机处理。
- `housheng-online-0.2.4.apk`：后生 AI。在后生的基础上加入 Clef API 和信息流筛选，只多一项网络权限。小红书 9.49.0 发现页卡片标题，抖音、抖音极速版 40.6.0 和快手、快手极速版 14.8.40 推荐页视频文案，命中后高斯模糊遮挡，可点“显示这条”恢复，视频不会自动划走。每个应用单独确认开启，默认全部关闭，API 凭据由本人配置并在手机加密保存。

这一版还修了大字号下应用清单闪退、小屏弹窗点不到、底部按钮一字一行、平板内容过宽，以及部分系统设置页打不开时没有备用入口。

抖音和快手的筛选只用小米 10S 上采到的界面结构离线验证过，还没在真机上运行。模型只看标题和文案，不理解画面。

之前装过调试包或 clef-preview 的手机，签名不同，需要先卸载再安装，本机设置和统计会清空。SHA256SUMS 可核对下载完整性。
