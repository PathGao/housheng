# 后生

**把信息的主动权拿回自己手里。**

[![CI](https://github.com/PathGao/housheng/actions/workflows/ci.yml/badge.svg)](https://github.com/PathGao/housheng/actions/workflows/ci.yml)

手机里哪些消息值得留下，哪些内容今天不想看，应该由自己决定。后生是一款中文 Android 信息流助手，从帮爸妈管理通知做起，也计划帮助年轻人按自己的意愿筛选内容、接触新话题、暂时回避不想看的信息。

当前是家庭试用版。你可以先和父母一起看清通知来自哪里、出现多频繁，再决定保留哪些、清理哪些。报告由父母预览后主动分享，规则在他们的手机上调整。

[开始试用](#开始试用) · [查看路线图](docs/roadmap.md) · [查看验证记录](docs/device-validation.md)

## 现在能用来做什么

| 想解决的问题 | 后生现在能做的事 |
|---|---|
| 不知道哪个应用总在发通知 | 选择要管理的来源，查看最近 7 天或 30 天的次数和处理汇总 |
| 想减少某些推广通知，又怕漏掉有用消息 | 自己设置清理关键词，也可让某个来源始终放行。电话、消息、闹钟及常驻等受保护通知保留 |
| 孩子想帮忙，但不在身边 | 预览后复制或分享家庭报告，让孩子据此建议如何调整 |
| 想知道手机最近装了什么 | 主动查看系统可见、有桌面入口的应用，标记近 30 天首次安装，必要时打开系统详情，由本人决定是否卸载 |

**真实抖音、快手、小红书的信息流筛选尚未开放。** 当前通知清理使用本地关键词。AI 判断与自动下滑已经在独立的合成验证场跑通，模型在电脑上运行，尚不能据此宣称能过滤日常刷到的视频。

2026-10-03，家庭版和模型管线已在小米 10S、Android 13 完成功能验证。长期后台稳定性、锁屏省电和重启后的恢复仍待日常使用验证。具体结果见 [家庭版验证](docs/device-validation.md)和 [模型管线验证](docs/laya-validation.md)。

## 开始试用

需要 Android 11 或以上系统。目前提供开发调试包，适合愿意一起反馈问题的家庭试用。

从 [GitHub 构建记录](https://github.com/PathGao/housheng/actions/workflows/ci.yml)打开一次成功运行，下载 `housheng-debug-apks`，解压后安装 `app-debug.apk`。仓库有访问限制时，需要先登录有权限的 GitHub 账号。日常使用无需安装独立验证场 `fixture-debug.apk`。

1. 打开后生，进入“管理通知”，按提示授予通知使用权。
2. 勾选想管理的应用，先保持“按规则清理通知”关闭，只观察次数。
3. 和家人查看“家庭报告”，确定关键词及需要始终放行的来源，再开启清理。
4. 需要停止时，在首页点击“暂停所有自动处理”。观察记录仍会保留，也可在系统设置撤销通知使用权。

日常通知管理、报告和应用清单**不需要无障碍权限**。无障碍仅用于“设置与诊断”中的验证场测试，不必为试用通知功能开启。

清理发生在通知到达之后，已经响起的声音或弹出的横幅可能仍会出现。想关闭某个来源的通知，可以直接使用“系统通知设置”入口。

覆盖安装要求签名一致。已经安装本机开发包的手机，应继续使用同一工具链生成的包更新。CI 调试签名可能不同，出现签名冲突时不要为安装新版贸然卸载，以免丢失本机记录。CI 安装包保留 14 天。

## 你的资料和决定权

后生只处理你勾选的名单内来源。浏览器、聊天类和名单外应用不采集内容。首批信息流适配范围是抖音、快手、小红书及所列极速版，真实页面适配完成前保持关闭。

通知标题和正文不持久化，本机只保留最近 30 个自然日的通知汇总。家庭报告不包含通知正文、验证码或私聊，也不会自动发给孩子。应用清单按需查询，默认不附入报告。没有账号、远程控制或自动同步。

常规发行构建不请求网络权限。家庭调试包保留默认关闭的本机模型验证入口，只能经 USB 访问电脑上的模型，且仅处理合成验证场。现在没有云模型接入。

后生不做广告屏蔽，不点击“跳过广告”，不绕过应用限制，不自动卸载应用。广告与无法确认类型的页面不自动操作。完整的数据范围、授权和统计口径见 [应用范围与隐私](docs/app-scope.md)。

## 接下来想做到

前期先让真实信息流筛选跑得快、判断后执行可靠，并提供误筛后的放行调整。在这条链路稳定后，逐步支持个人使用。

| 方向 | 用户可以表达的要求 |
|---|---|
| 质量筛选 | “少看标题党和没有依据的绝对承诺，按我选定的标准筛选。” |
| 拓展视野 | “给平时很少接触的话题和不同来源留一点时间。” |
| 临时回避 | “今天不想看某类信息，到期再恢复。” |
| 内容解说 | “这条内容我还想看，但请告诉我哪里值得核实、可以怎么做。” |

以上尚未实现。不同意见不自动等于低质量，暂时回避也不应变成永久兴趣标签。过滤只能减少已有内容，主动拓展视野还要解决新内容的来源。规则由本人设定、查看和解除，解释内容按需加载，不让长文本生成拖慢浏览。

后续若引入产品推广，将明确标识，并服从用户的筛选和回避规则。付费不能购买放行资格。

进度、验收条件和已确定的取舍见 [路线图](docs/roadmap.md)。

## 开发与验证

使用 JDK 17、Android SDK 35 和仓库内的 Gradle Wrapper。最低系统为 Android 11，Android Gradle 插件为 8.9.2，Kotlin 为 2.1.20。配置好 `JAVA_HOME` 和 `ANDROID_HOME` 后运行：

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :fixture:lintDebug :app:assembleDebug :fixture:assembleDebug
```

主程序产物为 `app/build/outputs/apk/debug/app-debug.apk`，验证场为 `fixture/build/outputs/apk/debug/fixture-debug.apk`。已有本地 `.tools/` 工具链时，可用 `scripts/build-local.sh` 替代 `./gradlew`，其他机器无需复制开发者的本地环境。

CI 执行单元测试、静态检查、调试与发行构建，并确认发行构建没有网络权限。模型协议测试不下载模型、不使用 API 密钥。设备测试只在 CI 编译，真机运行另见 [测试操作](docs/device-validation.md)。

| 入口 | 用途 |
|---|---|
| `app/` | 后生主程序、通知管理与家庭报告 |
| `fixture/` | 独立合成验证场，验证翻页和保护边界 |
| `scripts/test-device.sh` | 已授权设备上的功能测试与服务恢复 |
| [本机模型验证](validation/laya/README.md) | Laya 桥接、固定决策协议与替换模型的方法 |
| [界面设计](docs/product-design.md) | 家庭版页面与适老取舍 |
| [正式图标](design/icon/README.md) | 黑猫折扇图标与启动图标资源说明 |

反馈问题时，请附手机型号、Android 版本、操作步骤及首页显示的服务状态。报告或截图先检查个人信息，不需要提供真实通知正文。
